## Подключение Google Таблицы (≈ 3 минуты, один раз)

Ответы будут падать сразу в два места: в **Google Таблицу** и в файл **`ответы_гостей.txt`**
на вашем Google Диске (рядом с таблицей).

1. Откройте https://sheets.new — создастся новая таблица. Назовите её, например, «Юбилей 45 — ответы».
2. В меню таблицы: **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте содержимое файла
   [`google-apps-script/Code.gs`](google-apps-script/Code.gs). Нажмите 💾 (Сохранить).
4. Вверху выберите функцию **`setup`** и нажмите **▶ Выполнить**.
   Google попросит разрешения:
   «Проверить разрешения» → выберите свой аккаунт →
   «Дополнительные настройки» → «Перейти к проекту (небезопасно)» → «Разрешить».
   *(Предупреждение стандартное: скрипт ваш собственный, Google его просто не проверял.)*
   В таблице появится лист «Ответы», а на Диске — `ответы_гостей.txt`.
5. Справа вверху: **Начать развертывание → Новое развертывание**.
   - Шестерёнка «Выберите тип» → **Веб-приложение**
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
   - **Начать развертывание** → скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. Вставьте этот URL в `config.js`:
   ```js
   window.INVITE_CONFIG = {
     scriptUrl: "https://script.google.com/macros/s/……/exec"
   };
   ```
   Можно прямо на GitHub: откройте `config.js` в репозитории → ✏️ → вставьте → **Commit changes**.
   Через 1–2 минуты сайт обновится.

**Проверка:** откройте URL из шага 5 в браузере — должно быть написано
«Приёмник ответов работает. Ответов получено: 0». Потом отправьте тестовый ответ с сайта
и убедитесь, что он появился в таблице (тестовую строку потом можно удалить).

> Если позже поменяете `Code.gs`, делайте **Развертывание → Управление развертываниями → ✏️ → Версия: новая**,
> тогда адрес `/exec` останется прежним.

## Как это устроено

- Хостинг — GitHub Pages (бесплатно), сайт обновляется после каждого коммита в ветку `main`.
- Анкета отправляет `firstName`, `lastName`, `attending` (`yes`/`no`) POST-запросом в Google Apps Script.
- Ответ запоминается в браузере гостя: при повторном заходе он видит свой ответ и может его изменить
  (новый ответ добавится новой строкой — смотрите самую нижнюю строку по человеку).
